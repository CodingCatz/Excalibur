# Excalibur — 遊戲企劃工作室

一套網頁版遊戲企劃工具（PWA），涵蓋遊戲設計文件、流程圖、對話樹、數值表、資源清單、本地化管理、關卡佈局等功能。

線上使用：https://codingcatz.github.io/Excalibur/

---

| 模組 | 說明 |

## 設計文件 (GDD)

富文本遊戲設計文件編輯器，支援多種文件模板。

### 使用方式

- 輸入 `/` 可開啟快速指令選單（斜線選單），用方向鍵瀏覽、Enter 選取
- 工具列支援標題（H1–H5）、粗體、斜體、列表、引用、程式碼等格式
- 📑 **大綱面板** — 列出文件所有標題，點擊即可跳轉到對應位置
- 📊 **表格** — 插入可編輯表格（支援欄列增減、合併儲存格）
- ⚙ **機制區塊** — 描述遊戲機制的特殊區塊，例如：戰鬥系統、經濟系統
- 📝 **設計筆記** — 附加討論或待辦提醒
- 📊 **參數表** — 內嵌數值表格，快速定義數值參數

### 範例：使用斜線選單

在編輯器內輸入 `/` 後，可選擇：

| 指令 | 效果 | 使用情境 |
|------|------|----------|
| `/heading1` | 插入一級標題 | 章節大標題（如「核心玩法」） |
| `/heading2` | 插入二級標題 | 子章節（如「戰鬥系統」） |
| `/table` | 插入表格 | 參數列表、比較表 |
| `/blockquote` | 引用區塊 | 設計原則、參考資料 |
| `/code` | 程式碼區塊 | 偽代碼、配置範例 |
| `/mechanic` | 機制區塊 | 描述遊戲系統運作方式 |
| `/note` | 設計筆記 | 待討論事項 |

### 快捷鍵

| 快捷鍵 | 功能 |
|--------|------|
| `/` | 開啟斜線指令選單 |
| `Ctrl+B` / `⌘B` | 粗體 |
| `Ctrl+I` / `⌘I` | 斜體 |
| `Ctrl+Z` / `⌘Z` | 復原 |
| `Ctrl+Shift+Z` / `⌘Shift+Z` | 重做 |

### 文件模板

| 模板 | 用途 | 適合場景 |
|------|------|----------|
| 完整 GDD | 涵蓋概述、核心玩法、故事、關卡、UI、音效、技術規格 | 正式企劃提案 |
| 單頁企劃書 | 一頁式遊戲概念提案 | 快速 Pitch、遊戲 Jam |
| 系統設計書 | 特定遊戲系統的深入設計規格 | 戰鬥系統、經濟系統 |
| 關卡設計書 | 單一關卡的佈局、敵人、獎勵設計 | 關卡企劃 |
| 角色設計書 | 角色資料、性格、技能、數值、視覺設計 | 角色企劃 |
| UI/UX 規格書 | 畫面流程、HUD、選單設計 | UI 規劃 |

### 特殊區塊

- **狀態標記**：已確認 ✅ / 討論中 🔍 / 待修改 📝 — 追蹤文件審核狀態
- **修改紀錄**：追蹤文件變更歷史（誰在何時改了什麼）
- **參數表**：內嵌數值表格，例如在角色設計書中直接放入角色數值表
- **流程圖嵌入**：引用專案內的流程圖，點擊可跳轉
- **對話樹嵌入**：引用專案內的對話樹
- **跨文件引用**：連結其他 GDD 文件（如「詳見戰鬥系統設計書」）

### 匯入匯出

- 匯入：Markdown、JSON
- 匯出：Markdown、JSON、PDF、DOCX

## 流程圖 / 狀態機

節點式流程圖與狀態機編輯器，適合設計遊戲流程、AI 行為、UI 導航等。

### 使用方式

- 點擊工具列圖示新增節點
- 從節點邊緣拖曳到另一個節點建立連線
- 🖱 **右鍵**點擊節點或連線可刪除、編輯標籤、切換線型
- 📐 **自動排版** — 重新排列所有節點為整齊的樹狀佈局
- 📋 **模板** — 一鍵載入預設流程（如戰鬥流程、商店流程）
- 💻 **Mermaid** — 檢視 / 複製 Mermaid 語法，可貼到其他文件使用

### 快捷鍵

| 快捷鍵 | 功能 |
|--------|------|
| `Ctrl+Z` / `⌘Z` | 復原 |
| `Ctrl+Shift+Z` / `⌘Shift+Z` | 重做 |
| `Delete` / `Backspace` | 刪除選中的節點或連線 |

### 節點類型

| 節點 | 用途 | 外觀 | 範例 |
|------|------|------|------|
| 開始 | 流程入口 | 綠色圓角 | 「遊戲開始」 |
| 結束 | 流程出口 | 紅色圓角 | 「遊戲結束」 |
| 流程 | 一般處理步驟 | 藍色方塊 | 「載入場景」、「播放動畫」 |
| 判斷 | 條件分支 | 橙色菱形 | 「HP > 0?」、「有鑰匙?」 |
| 狀態 | 狀態機節點 | 紫色圓角 | 「待機」、「攻擊中」、「受傷」 |
| 子流程 | 引用其他流程圖 | 深藍雙框 | 「→ 戰鬥子系統」 |
| 備註 | 標注說明 | 黃色 | 「這裡需要音效」 |

### 連線

- 支援**圓角折線、貝茲曲線、直線、階梯**四種線型
- 右鍵連線可加入標籤文字，例如判斷節點的「是」/「否」分支
- 支援雙向連線（兩端都有箭頭）

### 範例：AI 狀態機

```
[待機] --發現敵人--> [追擊]
[追擊] --進入攻擊距離--> [攻擊]
[攻擊] --攻擊結束--> [追擊]
[追擊] --脫離視野--> [待機]
[攻擊] --HP < 30%--> [逃跑]
[逃跑] --到達安全點--> [待機]
```

### 流程模板

| 模板 | 說明 |
|------|------|
| 遊戲主流程 | 開始 → 主選單 → 遊戲 → 暫停/結束 |
| 戰鬥流程 | 回合制/即時制戰鬥的完整流程 |
| UI 導航 | 畫面之間的切換關係 |
| AI 狀態機 | 敵人 AI 行為狀態轉移 |
| 對話流程 | NPC 對話觸發與分支流程 |
| 新手引導 | 教學關卡的步驟流程 |
| 商店流程 | 購買/販賣/強化的完整流程 |

### 匯入匯出

- 匯入：Mermaid、JSON
- 匯出：Mermaid、SVG、PNG、JSON

## 對話樹

分支對話系統編輯器，支援角色管理、變數系統和對話模擬。

### 使用方式

- 點擊工具列圖示新增節點
- 從節點底部拖曳連線到其他節點
- 點擊節點開啟右側屬性面板編輯內容
- 📐 **自動排版** — 重新排列所有節點
- 📋 **套用模板** — 快速建立常見對話結構
- 🖱 **右鍵**點擊節點或連線可刪除、編輯標籤、切換線型
- 📦 **變數管理** — 新增/編輯對話變數

### 快捷鍵

| 快捷鍵 | 功能 |
|--------|------|
| `Ctrl+Z` / `⌘Z` | 復原 |
| `Ctrl+Shift+Z` / `⌘Shift+Z` | 重做 |
| `Delete` / `Backspace` | 刪除選中的節點或連線 |

### 節點類型

| 節點 | 用途 | 範例 |
|------|------|------|
| 入口 | 對話起始點 | 每段對話的開頭 |
| 出口 | 對話結束點 | 對話結束、回到遊戲 |
| 對話 | 角色說話 | NPC：「歡迎來到我的商店！」 |
| 選項 | 玩家選擇分支 | ① 買東西 ② 賣東西 ③ 離開 |
| 條件 | 根據變數判斷走向 | 「好感度 ≥ 50?」 |
| 動作 | 修改變數、觸發事件 | 「好感度 +10」、「獲得道具」 |
| 隨機 | 隨機選擇分支 | 50% 機率觸發特殊對話 |

### 角色管理

- 新增角色並指定名稱（如「商人 NPC」、「公主」）
- 連結資源清單中的美術資源（角色立繪）
- 12 種表情選項：平靜、開心、難過、生氣、驚訝、害怕、困惑、厭惡、興奮、害羞、得意、疲憊

### 變數系統

用變數控制對話分支和遊戲狀態：

| 變數類型 | 範例名稱 | 預設值 | 用途 |
|---------|---------|--------|------|
| 數值 | `好感度` | 0 | 累積好感觸發特殊對話 |
| 數值 | `金幣` | 100 | 檢查是否買得起 |
| 文字 | `玩家名稱` | "" | 對話中稱呼玩家 |
| 布林 | `已完成支線` | false | 解鎖新對話選項 |

**條件節點範例**：
- `好感度 >= 50` → 走「信任路線」
- `金幣 < 100` → 走「買不起路線」
- `已完成支線 == true` → 出現新選項

**動作節點範例**：
- `好感度 += 10` — 增加好感
- `金幣 -= 50` — 扣除金幣
- `已完成支線 = true` — 標記任務完成

### 對話模擬器

像玩遊戲一樣測試對話分支，不用啟動遊戲引擎：

- 即時顯示所有變數的當前值
- 操作歷程可隨時回退檢查
- 支援多入口選擇（測試不同起點）

**模擬器快捷鍵**

| 快捷鍵 | 功能 |
|--------|------|
| `Space` / `Enter` | 推進對話 |
| `←` 方向鍵 | 回退一步 |
| `→` 方向鍵 | 前進一步 |
| `1`–`9` 數字鍵 | 直接選擇對應編號的選項 |
| `Esc` | 關閉模擬器 |

### 對話模板

| 模板 | 說明 |
|------|------|
| NPC 商店對話 | 買賣選項、金幣檢查、庫存系統 |
| 支線任務 | 接受/拒絕、進度回報、獎勵發放 |
| 分歧劇情 | 多條件分支、好感度影響結局 |
| 教學引導 | 步驟式說明、操作提示 |

### 匯入匯出

- 匯入：Mermaid、JSON
- 匯出：Mermaid、SVG、PNG、Markdown、引擎 JSON（對話格式）、JSON

## 數值表

試算表式遊戲數據管理，支援公式計算、成長曲線和多種欄位類型。

### 使用方式

- ＋ 新增資料列（一列 = 一筆資料，如一個角色、一件武器）
- 📊 新增欄位（一欄 = 一個屬性，如 HP、攻擊力、稀有度）
- 點擊欄位標頭可排序，點擊 ⚙ 齒輪可編輯欄位設定
- 勾選列前的核取方塊 → 可批次編輯或刪除
- 分組功能：依選項或布林欄位分組（如按稀有度分組檢視）

### 快捷鍵

| 快捷鍵 | 功能 |
|--------|------|
| `Ctrl+Z` / `⌘Z` | 復原 |
| `Ctrl+Shift+Z` / `⌘Shift+Z` | 重做 |
| `Ctrl+Y` / `⌘Y` | 重做（替代） |

### 欄位類型

| 類型 | 說明 | 範例 |
|------|------|------|
| 文字 | 一般文字輸入 | 角色名稱 `勇者`、描述 `初始角色` |
| 數字 | 數值輸入（可設定範圍） | HP `1000`、攻擊力 `50`、移動速度 `3.5` |
| 選項 | 下拉選單 | 稀有度 `普通/稀有/傳說`、元素 `火/水/風/地` |
| 複選 | 多選勾選 | 弱點 `[火, 雷]`、技能標籤 `[AOE, 增益]` |
| 布林 | 核取方塊 | 可交易 `✓`、隱藏道具 `✗` |
| 公式 | 自動計算（唯讀） | 有效 HP = `hp * (1 + def / 100)` |
| 引用 | 引用其他數據表 | 裝備 → 引用武器表 `鐵劍` |
| 成長曲線 | 視覺化數值成長 | 經驗值曲線（見下方說明） |
| 機率 | 百分比或小數 | 掉落率 `15%`、暴擊率 `0.05` |
| 範圍 | 最小~最大值 | 傷害範圍 `10~25`、生成數量 `1~3` |
| 多語言鍵 | i18n 翻譯鍵 | `item.sword.name`（連結本地化管理） |
| 資源引用 | 引用資源清單 | 圖示 → 引用資源 `icon_sword_001` |
| JSON | 結構化資料 | 任務目標 `{"type":"kill","target":"slime","count":10}` |

### 公式語法

公式欄位使用 [mathjs](https://mathjs.org/) 語法，可直接引用同一列的其他欄位名稱作為變數：

#### 基本運算

| 公式 | 說明 | 假設值 | 結果 |
|------|------|--------|------|
| `hp * 0.5 + def` | 有效防禦力 | hp=1000, def=50 | 550 |
| `atk * (1 + crit_rate)` | 含暴擊攻擊力 | atk=100, crit_rate=0.15 | 115 |
| `base_exp * level ^ 1.5` | 升級所需經驗 | base_exp=100, level=10 | 3162 |
| `price * 0.6` | 賣出價格（6 折） | price=500 | 300 |

#### 常用函式

| 函式 | 說明 | 範例 | 結果 |
|------|------|------|------|
| `max(a, b)` | 取最大值 | `max(atk - def, 1)` | 傷害不低於 1 |
| `min(a, b)` | 取最小值 | `min(0.1 * level, 0.95)` | 機率上限 95% |
| `ceil(x)` | 向上取整 | `ceil(hp * 0.1)` | HP 回復量（進位） |
| `floor(x)` | 向下取整 | `floor(exp * 1.5)` | 經驗獎勵（捨去） |
| `round(x)` | 四捨五入 | `round(atk * 1.05)` | 強化後攻擊力 |
| `sqrt(x)` | 平方根 | `sqrt(str * dex)` | 迴避率基數 |
| `abs(x)` | 絕對值 | `abs(atk - def)` | 傷害差值 |
| `pow(x, n)` | 次方 | `pow(1.1, level)` | 指數成長 |
| `log(x)` | 自然對數 | `10 + 5 * log(level)` | 對數成長 |

#### 條件式

使用三元運算子 `(條件) ? 真值 : 假值`：

```
(is_boss == 1) ? hp * 2 : hp          → Boss 雙倍 HP
(level >= 10) ? atk + 50 : atk        → 10 級以上加 50 攻擊
```

### 成長曲線

成長曲線欄位可視覺化設定數值隨等級變化的成長趨勢，設定後可即時預覽圖表。

#### 曲線類型

| 類型 | 計算公式 | 適用場景 | 範例 |
|------|---------|---------|------|
| **線性** | `基礎值 + 成長值 × 等級` | 穩定成長 | 每級 +50 HP |
| **指數** | `基礎值 × 成長值 ^ 等級` | 後期爆發 | 怪物 HP 每級 ×1.1 |
| **對數** | `基礎值 + 成長值 × ln(等級)` | 遞減收益 | 技能冷卻減少 |
| **多項式** | `a₀ + a₁×等級 + a₂×等級² + …` | 複雜曲線 | 二次式成長 |
| **自定義** | 手動定義控制點，自動插值 | 完全自訂 | 不規則獎勵表 |

#### 成長曲線範例

**線性成長（角色 HP）**：基礎 500、成長 50

| 等級 | 1 | 10 | 25 | 50 | 99 |
|------|---|----|----|----|----|
| HP | 550 | 1000 | 1750 | 3000 | 5450 |

**指數成長（怪物 HP）**：基礎 100、成長 1.15

| 等級 | 1 | 10 | 25 | 50 |
|------|---|----|----|-----|
| HP | 115 | 404 | 3292 | 108,366 |

**對數成長（冷卻減少）**：基礎 10、成長 -2

| 等級 | 1 | 10 | 25 | 50 |
|------|---|----|----|-----|
| 冷卻(秒) | 10.0 | 5.4 | 3.6 | 2.2 |

**自定義曲線**：手動控制點 → 自動線性插值

| 控制點等級 | 1 | 10 | 30 | 50 |
|-----------|---|----|----|-----|
| 獎勵數量 | 1 | 5 | 10 | 12 |

等級 15 自動插值：7（介於 5 和 10 之間）

### 排程管理

每筆資源可設定製作排程，追蹤製作進度：

| 欄位 | 說明 | 範例 |
|------|------|------|
| 開始日期 | 排定開始日 | 2024-03-01 |
| 結束日期 | 排定完成日 | 2024-03-15 |
| 進度 | 完成百分比 | 60% |

#### 緊急度指標

系統根據**剩餘天數**與**完成度**自動計算緊急程度：

```
緊急度 = (100 - 進度) / (剩餘天數 / 總天數) × 100
```

| 緊急度 | 顏色 | 含義 | 範例情境 |
|--------|------|------|----------|
| < 50 | 🟢 綠色 | 進度正常 | 還有 10 天，已完成 70% |
| 50–79 | 🟡 黃色 | 需要注意 | 還有 3 天，才完成 50% |
| ≥ 80 | 🔴 紅色 | 進度告急 | 明天到期，才完成 20% |

## 本地化管理

多語系翻譯管理工具，支援分類、比對模式和翻譯進度追蹤。

### 使用方式

- ＋ 新增翻譯鍵，選擇分類
- 🌐 新增語系（可選預設或自訂語系代碼）
- 🔄 **同步 Key** — 掃描同專案的對話樹與數值表，自動匯入尚未建立的翻譯鍵
- 📊 **翻譯進度** — 檢視各語系翻譯完成率與缺翻數量

### 翻譯鍵分類

| 分類 | 說明 | 範例 |
|------|------|------|
| ui | 介面文字 | `ui.menu.start`、`ui.button.confirm` |
| dialogue | 對話文字 | `dialogue.npc_001.greeting` |
| quest | 任務文字 | `quest.main_001.title` |
| item | 道具名稱/描述 | `item.sword.name`、`item.sword.desc` |
| skill | 技能名稱/描述 | `skill.fireball.name` |
| system | 系統訊息 | `system.save.success` |

### 翻譯狀態流程

```
缺少翻譯 → 草稿 → 已翻譯 → 已審核 → 定稿
```

### 自動同步功能

點擊「同步 Key」後，系統會：

1. 掃描所有**對話樹**中的文字鍵（對話節點的 textKey、選項節點的 textKey）
2. 掃描所有**數值表**中的「多語言鍵」欄位值
3. 自動匯入尚未存在的翻譯鍵，並標記來源文件

**範例**：對話樹中有一個對話節點 textKey = `dialogue.shopkeeper.welcome`
→ 同步後自動在本地化管理中新增此 Key，分類為 `dialogue`

### 進階功能

- **比對模式**：並列對比兩個語系（如中文 vs 英文），方便逐條校對翻譯品質
- **主語系設定**：雙擊語系欄頭設為主語系，比對時固定顯示在左側
- **分類過濾**：只顯示特定分類（如只看 dialogue 類的翻譯鍵）
- **狀態過濾**：只顯示特定狀態（如只看「缺少翻譯」的項目）
- **搜尋**：模糊搜尋翻譯鍵名稱

### 匯入匯出

- 匯入：JSON（單一語系 flat JSON，如 `{"key": "value"}` 格式）
- 匯出：個別語系 JSON、全部語系一次匯出

#### 匯出 JSON 範例

```json
{
  "ui.menu.start": "開始遊戲",
  "ui.menu.settings": "設定",
  "dialogue.npc_001.greeting": "歡迎光臨！",
  "item.sword.name": "鐵劍"
}
```

## 關卡佈局

三種模式：節點圖、地圖標記、網格地圖。

### 節點圖模式

用節點與連線描繪關卡的空間結構與流程，適合設計地下城房間配置、城鎮區域規劃、世界地圖路線等。

#### 基本操作

- 工具列分三類：**結構**（房間、起點、Boss、商店、密室、出口）、**物件**（敵人、物品、NPC、觸發器）、**標註**（備註）
- 點擊工具列圖示新增節點，節點會放置在畫布上
- 拖曳節點邊緣的連接點（小圓點）到另一個節點即可建立連線（通道）
- 點擊連線可刪除
- **Auto Layout** 按鈕可自動排列所有節點

#### 節點屬性面板

選中節點後，右側彈出浮動屬性面板：

| 屬性 | 說明 | 用途案例 |
|------|------|----------|
| 名稱 | 節點顯示名稱 | `王座廳`、`B1 寶箱房`、`復活點 A` |
| 類型 | 切換節點類型 | 把「房間」改成「Boss」表示此處有 Boss 戰 |
| 說明 | 補充設計備註 | `需要鑰匙才能進入`、`觸發劇情後開放` |
| 連結關卡 | 連結其他關卡文件 | 門連到下一層地下城、傳送點連到城鎮 |
| 星等 | 1–5 星 | ★★★ 中等難度、★★★★★ 最終 Boss |
| 顏色 | 自訂節點顏色 | 紅色＝危險區、綠色＝安全區、紫色＝隱藏區 |
| 標籤 | 分類標籤（可多個） | `必經`、`支線`、`解謎`、`戰鬥` |

#### 標籤用途案例

標籤是自由文字，輸入後按 Enter 或 + 號新增：

| 情境 | 建議標籤 | 說明 |
|------|----------|------|
| 地下城設計 | `必經` `支線` `隱藏` `鑰匙` `寶箱` | 區分主線與探索路線 |
| 城鎮規劃 | `商業區` `住宅區` `王城` `港口` `地下` | 區分城鎮功能區域 |
| 世界地圖 | `第一章` `第二章` `DLC` `解鎖條件` | 標記進度與開放時機 |
| 戰鬥設計 | `近戰` `遠程` `陷阱` `增援` `精英` | 標記戰鬥特性 |
| 開發管理 | `TODO` `已完成` `需美術` `需測試` | 追蹤開發進度 |

#### 星等活用

所有節點類型都可設定星等（1–5 星），不限於 Boss 房：

- **區域難度**：★ 新手村、★★★ 中期區域、★★★★★ 終盤
- **重要性**：★ 可跳過的支線、★★★★★ 主線必經
- **設計優先度**：★ 之後再說、★★★★★ 必須先做好

### 地圖標記模式

在地圖上放置興趣點（POI）和區域（Area），適合世界地圖設計。

#### 操作方式

- 點擊 **POI** 按鈕後在地圖上點擊放置標記
- 點擊 **Area** 按鈕彈出形狀選擇器，選擇後在地圖上拖曳畫出範圍
- 選中標記後彈出**浮動屬性面板**，可編輯名稱、顏色、形狀、尺寸、星等、連結關卡等
- POI 編輯面板點擊**連線按鈕** → 點擊另一個 POI 建立連線；點空白處取消
- 點擊連線可開啟**連線編輯面板**：標籤、線型（圓角折線/貝茲曲線/直線/階梯）、虛線、雙向、刪除
- POI 可指定所屬區域，座標顯示為區域內相對座標
- 上傳背景圖作為地圖底圖

#### Area 形狀

## 操作規劃

視覺化的輸入裝置按鍵綁定編輯器，用互動式 SVG 圖解規劃遊戲控制方案。

### 裝置類型

| 裝置 | 說明 |
|------|------|
| 🎮 Gamepad | Xbox 風格手把 — ABXY、方向鍵、搖桿、肩鍵/扳機、功能鍵 |
| ⌨️ Keyboard + Mouse | 鍵盤 + 滑鼠 — 精簡模式（WASD 區）/ 完整模式（全鍵盤 + 數字鍵盤） |
| 📱 Touch | 觸控螢幕 — 虛擬搖桿、按鈕、手勢區域 |

### 使用方式

1. **建立方案** — 工具列點擊 `+` 按鈕，選擇裝置類型後輸入方案名稱（如「戰鬥模式」「探索模式」）
2. **選取按鍵** — 點擊 SVG 圖上的按鍵，右側面板開啟綁定編輯
3. **設定綁定** — 填寫行為名稱（如 Jump、Attack）、分類、描述、長按/連按行為
4. **多方案切換** — 工具列切換不同方案（tab 風格），雙擊方案名可重命名
5. **鍵鼠模式切換** — 鍵盤+滑鼠裝置右上角可切換「精簡 ⇄ 完整」模式

### 鍵盤＋滑鼠模式

- **精簡模式**：ESC、F1–F4、數字 1–5、WASD 周邊 + 滑鼠，適合快速規劃核心操作
- **完整模式**：全 QWERTY 鍵盤（含 F1–F12）+ 下方面板（導航鍵、方向鍵、Numpad、滑鼠）

### 綁定面板

- **行為名稱**：顯示在 SVG 按鍵旁的 badge（超過 6 字自動截斷）
- **分類**：自訂分類標籤（如 Movement、Combat、UI）
- **描述**：詳細行為說明
- **長按行為**：按住該鍵的替代功能
- **連按行為**：快速連按的替代功能

### 匯入匯出

- 操作方案隨文件一起儲存，支援雲端備份
- 可建立多組方案比較不同控制設定

## 雲端備份與還原

### 備份方式

- 側邊欄點擊 ☁️ 雲端備份按鈕 → 彈出確認對話框，顯示目前備份位置
- 確認後將**當前專案**上傳至 Google Drive（不會同步其他專案）
- 首次備份會在 Google Drive 建立「Excalibur」資料夾
- 編輯內容自動存到瀏覽器本地（3 秒防抖），雲端備份需手動觸發

### 備份確認對話框

點擊備份按鈕後會看到：

- **備份位置**：顯示目前資料夾名稱（hover 顯示完整路徑，如 `My Drive > Excalibur`）
- **切換位置**：點擊資料夾名稱可開啟 Google Picker 選擇新位置（既有備份會自動搬移）
- **確定** / **取消**：確認後才執行備份

> 範例：團隊共編時，User B 可在備份對話框中切換到 User A 分享的資料夾，之後雙方都備份到同一個位置。

### 從雲端還原

1. 首頁點擊「從雲端還原」按鈕
2. 登入 Google 帳號（首次使用需授權）
3. 選擇要還原的專案 → 選擇版本 → 確認還原
4. 還原對話框可切換「我的雲端硬碟」或「共用與我」分頁

### 搬移專案

兩種搬移方式：

| 方式 | 操作 | 說明 |
|------|------|------|
| **備份時搬移** | 備份對話框 → 點擊資料夾名稱 → 選新位置 | 搬移 + 備份一次完成 |
| **純搬移** | 專案名稱旁的 📁 搬移按鈕 | 只搬移不觸發備份 |

### 版本歷史

- 側邊欄點擊 🕐 版本歷史按鈕，檢視該專案的所有雲端備份版本
- 可選擇任一歷史版本進行還原
- 每次備份都會產生一個帶時間戳的版本

### 分享雲端連結

- 側邊欄點擊 🔗 分享按鈕，自動設定**唯讀**權限並複製 Drive 連結
- 對方可在瀏覽器直接檢視備份內容（不需要安裝本工具）
- 如需共編，請在 Google Drive 手動將資料夾設為「可編輯」

### 共編工作流

1. User A 建立專案、備份到 Drive
2. User A 點擊分享按鈕取得連結，傳給 User B
3. User A 到 Google Drive 將資料夾設為「知道連結的人可編輯」
4. User B 開啟本工具 → 備份按鈕 → 點擊資料夾名稱 → 在 Picker「共用與我」分頁選擇 User A 的資料夾
5. 雙方備份/還原都指向同一個 Drive 資料夾

> 注意：目前為輪流編輯模式（非即時協作），雙方同時編輯可能導致版本覆蓋。

## 通用功能

### 專案管理

- 新增**空白專案**或使用**全模板示範專案**快速體驗所有功能
- 專案清單支援重新命名（點擊 ✏️ 編輯按鈕）
- 支援匯入：ZIP 匯入（本地）/ 雲端還原 / 貼上 Drive 連結
- 支援匯出：ZIP 打包（含 Markdown + Mermaid + JSON）、合併 Markdown、PDF
- Google Drive 雲端備份（僅同步當前專案，不影響其他專案）

### 跨文件引用

每個編輯器工具列右側的 🔗 按鈕可開啟**引用面板**，檢視：

- **被引用**：哪些文件引用了當前文件
- **引用中**：當前文件引用了哪些其他文件
- **失效引用**：引用的目標文件已被刪除

點擊引用項目可直接跳轉到對應文件。

### 資料儲存

- 所有編輯內容即時自動儲存到瀏覽器 IndexedDB（3 秒防抖）
- 可手動備份到 Google Drive
- 離線可用（PWA）

### 匯出格式

除各模組專屬匯出外，還支援：
- **全專案合併 Markdown** — 所有文件合成一份可讀文件，含目錄
- **ZIP 打包** — 全專案所有文件打包下載（JSON + 人類可讀格式）

### 多語系

介面支援繁體中文、English、日本語
